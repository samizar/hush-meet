## Recording recovery release v1.1.1

- Diagnosed a stopped recording with a nonempty microphone WAV and a zero-frame other-side WAV, using state, file sizes and frame counts only. The previous empty-channel recognizer regression did not finish within a bounded 25-second run.
- Speech analyzers now start only after their first audio buffer. Structured analysis finalizes at the last consumed sample; empty inputs cancel immediately. Converter tails are flushed, native recognizers are cancelled on failure, and the recording session bounds its final speech wait at 20 seconds.
- Real Apple Speech regression passes: a synthetic microphone recording plus an empty other-side channel drains both WAVs and finalizes a nonempty Me transcript in approximately 0.7 seconds. Empty input, a 0.1-second silent input, cancellation before the first buffer, and two simultaneous spoken channels also pass. No private meeting speech was used.
- All 112 tests pass with both real Apple Speech and Foundation Models integrations enabled. Synthetic notes generation completes in approximately 10 seconds. The final standard suite and network boundary audit also pass.
- Processing cleanup releases controls after failure, cancellation and missing-meeting paths. Notes generation and file transcription have deadlines; late callbacks are fenced by capture generation. Users can cancel processing while retaining saved files.
- Both model buttons were clicked in an isolated app preview: Apple Speech reported readiness for English (Finland), and on-device notes generated a sample successfully with visible progress and an inline success result.
- The Models tab explains why settings are temporarily unavailable during a meeting. Apple Speech readiness and actual on-device notes generation show local progress, bounded execution and inline results. Privacy settings expose local rotating diagnostics, limited to fixed events and numerical metadata. Tests verify content exclusion, private permissions and two-file rotation.

- The final app (1.1.1, build 6) and approximately 2.2 MB DMG are signed for team `ZUT6837GB5`, have attached Apple tickets and pass Gatekeeper as `Notarized Developer ID`. The fresh public GitHub download passes SHA-256 and both Ed25519 feed/payload verification checks.

After promotion to stable, the exact `releases/latest/download/appcast.xml` URL embedded in Hush offers 1.1.1. The feed retains the previous 1.1.0 item. ## Side notes and local model release v1.2.0

- Added a persistent side-note editor for every meeting, available beside the summary in wide windows and inline in compact windows. The popover and notebook edit the same text. Autosaves serialize per meeting, patch only annotations, preserve processing/generated state, remain encrypted when enabled, and finish before normal app termination.
- Optional context controls and a context digest preserve compatibility with older meeting and preferences files. Excluded notes never enter the summary context. Included edits mark summaries stale and offer regeneration; original user notes remain separate. Long-meeting passes receive the same escaped background context, with an explicit error before any model request if side notes exceed the model budget.
- Dedicated Ollama and LM Studio / llama.cpp providers support explicit local model discovery, editable model/server selection and real synthetic generation tests. Remote HTTPS requirements remain intact. Loopback providers canonicalize localhost, pin scheme/host/port, refuse redirects and other hosts, and use no proxy configuration. Ollama routing metadata refuses cloud-backed and embedding-only models before sending meeting content.
- All 129 tests pass with real Apple Speech, Apple Foundation Models and local Llama integration enabled. The installed Ollama server's existing `llama3.2:latest` model produced a synthetic summary and an agenda action owned by Sam in approximately 15 seconds. Apple notes generation passed in approximately 18 seconds; all empty-channel speech regressions still pass. No models were downloaded, and no real meetings were used.
- New tests cover address spoofing and port boundaries, literal IPv6 loopback, local/cloud routing, schema requests and truncated output, encrypted annotation round-trips/search, backward decoding, context opt-out, prompt escaping, context budgets, rapid edits across meeting selections, and preventing deleted meetings from being resurrected by pending saves.
- Native UI inspection in an isolated sandboxed preview confirms side-note editing, context opt-out messaging, stale-summary indication and the wide-window layout. The Models tab discovers three installed chat models while omitting the embedding-only model. Selecting Llama 3.2 and clicking Test local notes completes successfully inside App Sandbox with the loopback transport setting. Preview data and settings remain isolated from the installed app.
- The 1.2.0 build 8 app and final DMG have valid Developer ID signatures for team ZUT6837GB5, attached Apple tickets and Gatekeeper acceptance. The fresh public GitHub download passes SHA-256 and Ed25519 feed/archive verification.
